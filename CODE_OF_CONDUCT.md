# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

**In short:** be respectful, assume good intent, keep discussions about the work, and no harassment of any kind.

Reports of unacceptable behaviour can be sent privately to the maintainer through the contact on <https://nanodev.io.vn/>. All reports are reviewed and handled confidentially.
