## en
### Unity project Library

Unity's import cache for this project: converted textures, meshes, shaders and the asset database. It is rebuilt from `Assets` and is never committed to version control.

**If you delete it:** nothing is lost, but the next time you open the project Unity re-imports everything, which can take minutes to hours on big projects.

**Instead:** close Unity first; delete only for projects you no longer open, or use Unity Hub to remove old projects.

## vi
### Thư mục Library của project Unity

Bộ đệm import của Unity cho project này: texture, mesh, shader đã chuyển đổi và cơ sở dữ liệu asset. Được tạo lại từ `Assets` và không bao giờ đưa vào version control.

**Nếu xóa:** không mất gì, nhưng lần mở project tiếp theo Unity phải import lại toàn bộ, có thể mất vài phút tới vài giờ với project lớn.

**Nên làm:** đóng Unity trước; chỉ xóa với project không còn mở, hoặc gỡ project cũ bằng Unity Hub.
