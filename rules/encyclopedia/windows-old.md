## en
### Previous Windows installation

A copy of the previous Windows version kept after a feature update or reinstall, so you can go back within about 10 days and recover files from the old install. It is removed automatically after a while.

**If you delete it:** you can no longer roll back to the previous version, and files left in the old user folders are gone.

**Instead:** check `Windows.old\Users` for anything you still need, then use Disk Cleanup → "Clean up system files" → "Previous Windows installation(s)".

## vi
### Bản cài Windows trước

Bản sao của phiên bản Windows cũ được giữ lại sau khi nâng cấp lớn hoặc cài lại, để có thể quay lại trong khoảng 10 ngày và lấy lại tệp từ bản cài cũ. Windows tự xóa sau một thời gian.

**Nếu xóa:** không quay lại phiên bản trước được nữa, tệp còn trong thư mục người dùng cũ mất luôn.

**Nên làm:** kiểm tra `Windows.old\Users` xem còn gì cần không, rồi dùng Disk Cleanup → "Clean up system files" → "Previous Windows installation(s)".
