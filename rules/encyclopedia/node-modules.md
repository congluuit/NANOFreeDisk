## en
### JavaScript dependencies (node_modules)

Packages installed by npm, pnpm, Yarn or Bun for one project, recreated from `package.json` and the lock file. Every project has its own copy, so old projects add up quickly.

**If you delete it:** nothing is lost; the project will not run or build until you install again.

**Instead / to restore:** run `npm install` (or `pnpm install`, `yarn`, `bun install`) in the project folder. Tools like pnpm share one store across projects and save a lot of space.

## vi
### Thư viện JavaScript (node_modules)

Các gói npm, pnpm, Yarn hoặc Bun cài cho một project, tạo lại được từ `package.json` và file lock. Mỗi project có bản riêng nên project cũ cộng lại rất nhanh.

**Nếu xóa:** không mất gì; project chỉ chạy/build lại được sau khi cài lại.

**Khôi phục:** chạy `npm install` (hoặc `pnpm install`, `yarn`, `bun install`) trong thư mục project. pnpm dùng chung một kho cho mọi project nên tiết kiệm rất nhiều.
